# AURA Public Website

A lightweight, responsive public website for AURA, built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Current scope

Part 1 foundation: shared header/navigation, responsive homepage, news listing with category filters and load-more behavior, article detail layout, match preview/analysis/knowledge landing pages, About, Contact & Help, legal page drafts, app download landing page, content-aware empty states, app promotion and footer.

The public pages intentionally contain no fabricated articles or unverified contact details. Legal pages are clearly marked drafts and must be reviewed against actual website/app practices before publication. News and article templates are ready for approved editorial content and licensed imagery. Direct-route hosting fallback, dependency/build checks and browser/device testing remain to be verified before launch.
